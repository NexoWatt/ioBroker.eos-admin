Lizenz aktivieren

Den für diese UUID ausgestellten Lizenzcode aus dem NexoWatt Key-Generator einfügen. Die Lizenz wird geprüft und verschlüsselt auf dem Gerät gespeichert.

Die gemeinsame EOS-Systemlizenz im Format NWL3 wird nach der Erstanmeldung einmalig aktiviert. Nach Neustarts bleibt sie gespeichert. Bestehende NWL2-Lizenzen behalten ihren ursprünglich signierten Umfang; alte NW1-Schlüssel benötigen eine passende Ersatzlizenz.

Der gespeicherte Code wird nicht zurück angezeigt. Ein ungültiger Import ersetzt keine gültige Lizenz.

Öffentliche Prüfschlüssel & Wiederherstellung

Hier werden die öffentlichen Schlüssel zur Lizenzprüfung verwaltet. Ein Import ergänzt ausschließlich bereits vom Hersteller freigegebene oder über die geschützte OS-Vertrauensdatei bestätigte Schlüssel. Er aktiviert keine zweite Lizenz.

Aktive Prüfschlüssel

Für einen Import zugelassene Schlüssel

Eine Herstellerfreigabe allein aktiviert einen Schlüssel noch nicht. Ohne OS-Einrichtung ist der ausdrückliche Import erforderlich.

Erwartet wird eine flache Zuordnung von Schlüssel-ID zu PUBLIC KEY im PEM-Format. Der Dateiname ist beliebig. Private Schlüssel, Tresor-Backups und gemischte Dateien werden vollständig abgewiesen.

Eine lokal wiederhergestellte Kopie ersetzt keine unabhängige Vertrauensfreigabe. Neue, unbekannte Aussteller benötigen eine autorisierte OS-Einrichtung oder eine neue Herstellerfreigabe.

Key-Generator auf einem neuen PC

Zum Wiederherstellen des privaten Signierschlüssels benötigen Sie das verschlüsselte Tresor-Backup und dessen Passphrase im Key-Generator. Beides gehört niemals in EOS. Eine öffentliche Schlüsseldatei kann den privaten Schlüssel nicht wiederherstellen.

Ohne gültige Lizenz bleiben Lizenzverwaltung, Diagnose und Sicherheitswartung erreichbar. Die Betriebsfreigabe der angebundenen Adapter endet spätestens nach 15 Sekunden. Schutzfunktionen benötigen den im jeweiligen Adapter festgelegten sicheren Zustand.
